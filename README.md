# FitLog

FitLog is a modern workout and fitness tracking web application that helps users explore different workouts, view workout details, and create a personal workout plan.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Lucide React

## Key Features

1. **Workout Library** — Browse and explore different workouts with useful information such as difficulty, duration, and equipment.

2. **Workout Details** — View detailed information and instructions for individual workouts.

3. **My Plan** — Add workouts to a personal workout plan and manage selected exercises.

4. **Responsive Design** — Fully responsive interface that works smoothly on desktop, tablet, and mobile devices.

5. **Toast Notifications** — Provides instant feedback when users add, remove, or complete workouts.
